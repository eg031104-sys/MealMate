## Reproduce and extend the batch

```sh
git clone https://github.com/ronaldl29/public-domain-recipes /tmp/mealmate-public-domain
git -C /tmp/mealmate-public-domain checkout 134e22f11e4d14e66ee587b1dd3a266e5646d387
node scripts/recipes/import-public-domain.mjs /tmp/mealmate-public-domain
npx prettier --write src/data scripts/recipes
npm test
npm run typecheck
npm run build
```

Requires Node, Python 3, Git and installed project dependencies. The importer refuses an unexpected source revision, duplicate IDs/titles and unresolved selected recipes. It preserves the two initial verified source records and rebuilds only this bundled batch; it never opens or changes household IndexedDB data.

`extract_sources.py` reads factual source metadata. `src/recipe-curation.ts` is the structured source adapter. `selection.json` assigns actual meal uses; `decisions.json` records reviewed parsing choices, optional omissions, amounts recovered from cooking steps, appliance requirements and safety clarifications. `selected-sources.json` is the selected original source snapshot. `source-audit.json` records automated findings for 243 finite-yield candidates: 140 have unresolved issues; 73 are selected in this stage; 30 other mechanically parseable records are **not** automatically quality-approved. The earlier banana cookies are already included independently. Beverages, sauces, unresolved subrecipes, repeated unit versions, incomplete methods and uncertain reuse rights are not used to fill meal-category quotas. No claim is made that all source files passed human review.

To add another batch, select distinct suitable dishes, review the original Markdown and cooking steps, record evidence-backed normalisation decisions, then run the importer and update the explicit count tests. Missing main ingredients, yields or oven temperatures must not be guessed. A handful, pinch or to-taste seasoning alone is no longer grounds for rejection.

## Measurements and portions

- The original measure is retained for display and source checking. Normalised quantities use grams, millilitres or counts. `approximate`, `estimateKey`, `estimateMultiplier` and `measurementNote` distinguish estimates from source amounts.
- Ingredient-specific rules include spinach 30 g/handful, parsley 15 g/handful, almonds and grated cheese 30 g/handful, salt 0.3 g/pinch and olive oil 5 mL/splash. There is no universal handful mass.
- Cup weights, produce sizes, cans and some packages are **configurable working estimates**, not exact source measurements or verified supermarket pack sizes. Explicit source package weights take precedence. Unspecified cup conventions are estimates using ingredient-specific working defaults; source words remain visible. International spoons use 15 mL/tablespoon and 5 mL/teaspoon, never silently treating a foreign tablespoon as an Australian 20 mL tablespoon. Ingredient-specific density estimates are labelled when converting volume to weight; otherwise the units remain separate. No universal weight/volume conversion is performed.
- Settings → **Approximate recipe measurements** supports search, temporary empty numeric drafts, validation and explicit Save. Saving recalculates recipe requirements while retaining purchases and pantry stock. Optional salt-to-taste grams are blank by default; clearing the estimate excludes that seasoning again.
- Unquantified seasonings, cooking water and optional accompaniments are retained but excluded from exact shopping quantities. The Shopping List calls them out and budget totals remain partial. This is not a claim that all costs are known.
- Scaling is `normalised quantity × people × appetite ÷ original yield`. Two handfuls of spinach (60 g), yielding two servings, require approximately **180 g for four people at 1.5×**. Finite source ranges use their lower stated yield, as authorised, with the original range displayed. Missing yields stay under review.
- Whites and yolks from the same separated eggs are counted once as whole eggs to purchase. Raw and prepared chicken remain separate inventory requirements; cooked ingredients are not replaced with raw stock.
